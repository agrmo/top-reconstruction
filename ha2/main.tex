\n{sturm}{(p(x)y')'+(q(x)+\lambda w(x)) y &= 0\quad a<x<b}
\n{slou}{Sturm-Liouville~}
\n{mlamt}{(-\lambda)^{1/2}}
\n{sso}{\sin(s_0)}
\n{cso}{\cos(s_0)}
For reference, the Sturm-Liouville form is
\e{a,b\in \mathbb{R}}
\e{\sturm}
\e{c_1 y(a) + c_2 y'(a) = 0}
\e{d_1 y(b) + d_2 y'(b) = 0}
\e{c_1 \neq 0 \textrm{ or } c_2 \neq 0}
\e{d_1 \neq 0 \textrm{ or } d_2 \neq 0}
The regularity conditions are
\e{\label{reg1} p(x),p'(x),q(x),w(x)\textrm{ continuous and } a\leq x \leq b}
\e{\label{reg2} p(x)> 0\quad w(x)> 0 \textrm{ and } a\leq x \leq b}
\section*{Problem 1}

\e{\label{12983n}p(x)=x\quad q(x)=0 \quad w(x)=1 \quad a=0 \quad b=1}
\e{\sturm\\
(x y')'+(q(x)+\lambda w(x))y&=0\\
xy''+y'+\lambda y&=0}
Check boundary conditions.
\e{x=0\quad \sturm\\
0+(0+\lambda)0&=0\\
0&=0}
\e{x=1\quad \sturm\\
y''+(0+\lambda)y&=0\\
0=0}
The problem satisfies boundary conditions. The problem is in \slou form with parameters \eref{12983n}. Check if regular.
\e{x=0\Rightarrow p(x)=0}
Condition \eref{reg2} is not satisfied. The problem \fbox{is in Sturm-Liouville form and singular}.
